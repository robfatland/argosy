This folder `~/argosy/som` contains files for the study of the **subsurface oxygen maximum (SOM)**:
a dissolved-oxygen inversion just below the mixed layer depth that the shallow profilers pick up
cleanly, and the open question of what causes it.

- **Status:** active (reviewed Nov 2026)
- **Purpose:** subsurface oxygen maximum (DO inversion below the MLD): interpretive framework, discriminating tests, examples
- **Next:** annotate the time intervals with a high-oxygen inversion (automated or by hand with the bundle chart); run the percent-saturation and diel (#9 minus #4) tests

- `SOM.md` -- the observation, four candidate causes (production in place, remnant, temperature
  solubility, sideways supply), a table of tests that tell them apart, three bundle-chart examples,
  and the open topics.

Related: `../MLDObservations.md` (where the inversion was first noted), `../vis/bundle_chart.py`
(the charts), `../images/` (the figures), `../seastate/` (forcing).
