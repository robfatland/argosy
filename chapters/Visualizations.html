Visualizations#

Views of data primarily taken from the shard redux<yyyy> files/folders.

  • bundle plot

  • curtain plot

  • bundle animation

Switching sites (sb / oo / ab): each plot cell below calls op.select_site(), which starts from the ARGOSY_SITE environment variable (default sb) and then prompts: press Enter to keep that default, or type a 2-letter code (sb/oo/ab) to switch. The chosen site is echoed on a confirmation line. No kernel restart or ARGOSY_SITE export is needed to change sites — just re-run the cell and answer the prompt.

Bundle plot#

  • redux is profile data sharded into a baseline or starting resource

  • pp01 is noon profiles only culled from redux

  • pp02 is midnight profiles only culled from redux

  • pp05 is a virtual dataset indicating only valid profiles by means of a manifest file

  • pp06 is a version of redux derived from the pp05 manifest plus application of ad hoc filters

    • see PP06_Filters.md

Year range is set via two input statements; everything else including data source is dynamically selected via a widget-based UI. Start time is rather slow (a couple of minutes).

curtain plot#

Sensor data are encoded as color and rendered profile-to-profile across the time axis. Vertical axis is depth from surface (0) down to the shallow profiler platform (200 meters).
